# 검수한 매뉴얼 FAQ

`reviewed.json`은 원본 PDF와 질문·답변 경계, 조건, 예외를 대조한 24건의 요약입니다. Codex가 검수했으며 사람의 최종 승인은 받지 않았습니다. 미검수 자동 추출 FAQ 1,173건을 일괄 수록한 자료가 아닙니다.

각 항목에는 원래 FAQ 질문, 검수한 답변 요약, 사업 별칭, 변환 원문 파일명·SHA-256·행 범위, 원본 PDF 파일명·SHA-256·물리 페이지 번호가 있습니다. 평가용으로 다시 작성한 질문, 채점 기준과 필수 사실 목록은 실행 자료에 포함하지 않습니다.

`welfare_index.py build`가 자료를 `manual_faq` 보조 테이블에 수록합니다. 모든 변환 원문 해시·연도·지역이 DB 문서와 일치해야 교체합니다. 검색 시 원문 해시가 바뀐 검수 항목은 제외합니다. 사업 별칭이 질문에 직접 나타나고, 연도·지역·질문 내용이 맞는 FAQ를 최대 두 건 선택하며, 기존 문단과 같은 근거 수·문자 예산 안에서 답변 전체를 우선 제공합니다.

이 자료와 `manual_faq_reviewed_priority24.json`은 같은 원문 사실을 사용합니다. 같은 24문항의 재평가는 개선 회귀 검사이며 독립된 민원 정답률 검증은 아닙니다. 전체 정답률은 추가 원문 검수 및 별도 민원 평가로 측정해야 합니다.

검수 FAQ가 선택되면 답변 생성과 근거 검증은 같은 FAQ 묶음을 사용합니다. 다른 사업의 일반 문단을 섞지 않으며, 질문한 추가 항목이 그 FAQ에 없으면 해당 항목이 FAQ에서 확인되지 않는다고 표시하도록 합니다. FAQ의 질문 범위를 넘어서는 복합 민원에서 다른 원문으로 보완하는 검색은 다음 평가에서 별도로 검증해야 합니다.

모자보건 지원율 변경 시점이 본문과 FAQ 사이에서 충돌하는 항목과 질문에 다른 답변이 붙은 항목은 수록하지 않았습니다. 확장할 때에는 원문 대조와 출처 기록을 먼저 완료해야 합니다.
